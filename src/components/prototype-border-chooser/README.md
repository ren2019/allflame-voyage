# #36：边界选择器确认原型

一次性评审原型，2026-10-16 由维护者确认。用于回答“如何在紧凑面积中快速选择边界词缀与同类档位”。仅保存在原型分支，不作为生产实现合并。

双击 `index.html` 即可查看；也可在仓库根目录运行：

```sh
python3 -m http.server 4186 --directory src/components/prototype-border-chooser
```

打开 `http://127.0.0.1:4186/`。`fragment.html` 是可编辑原始内容，`index.html` 是附带预览运行时的独立版本。两者只保存内存状态，不连接实际规划或持久化。

## 已确认

- 第一行显示当前边界词缀及数值，紧随其后只列其他同类档位；例如“物品稀有度 75% [50%] [100%]”。没有独立换档栏。
- 第二行搜索与清空，下面左侧分类目录、右侧词缀选择。
- 五类：怪物数量 6 类、收益经验 6 类、通货掉落 13 类、遭遇宝藏 7 类、特殊机制 7 类。经验不单设一类；既有 64 个词缀 ID 全部可选。
- 通货掉落使用现有游戏素材的可点击图标网格，附简短名称与完整说明；其他分类用紧凑的词缀行及档位按钮。
- 点击行名称或空白处选择首个可见档位，点击档位按钮选择该档位。搜索后默认选择首个可见匹配项，不能选隐藏档位。
- 当前词缀仍保留在所属分类；只通过蓝色高亮表示选择状态，不显示勾或“当前”字样。程序通过 `aria-pressed` 表达选择状态。
- 档位按数值从低到高。右侧家族与左侧分类应按各自汇总的出现权重降序，同权时保持稳定顺序。

## 权重数据缺口

原型没有真实边界出现权重，保留稳定顺序并明确标记数据待补。已检查 PoEDB Maiden Voyage 总表，以及 Divine Orb/Scarab 的 DeepwaterBorder 明细；未取得可用生成权重。禁止以策略适配分代替、把未知值当零或编造常见程度排名。排序规则已确认，真实数据仍需独立取得。
