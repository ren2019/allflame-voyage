# 区域目标：机制来源与展示权重建议

调查日期：2026-10-15。服务于 #14 的需求对齐；本文件不修改求解评分、产品代码或部署。权重仅决定每格最多四个图标的展示顺序，不能解释为掉落价值、收益比例、攻略最低分或是否值得 reroll。

## 证据口径

- 官方公告和补丁说明用于确认机制变更。
- 原策略作者的视频是“作者做过什么、建议什么”的一手材料，不等于官方机制说明或当前市场实测。
- PoEDB 是第三方游戏数据展示／datamine。可以确认数据中出现某条词缀，不能独自证明隐藏交互、实际产量、目的地固定数量或当前国服同步版本。
- 用户的《S30 航海海图·目的地与纪念币速查》作为玩家参考，未把其中价格、掉率、数量重新认证为官方事实。历史价格全部不进入权重。

## 调查阶段的机制分类及局部权重示例

完整且统一的建议以 [区域目标展示权重主表](region-target-priorities.md) 和配套 JSON 为准；本表用于记录调查时的分类与推断，不是第二份生效配置。

这是研究者给需求评审的初始排序，非游戏内置权重。建议统一使用 0–100：90–100 为策略核心，70–89 为值得主动寻找，40–69 为顺路优先，10–39 为补充目标，0 为仅详情中的状态。不同目标的差值不表示收益差值。

所有目标先要求 `present = true`，来源只能是已知目的地规则或该格实际收到的词缀；选中策略只改变排序和说明。未知随机祭坛只能提示“沿途留意”，不得假装已存在于特定区域。

## 只做条件／详情，不新增目标图标

物品数量、稀有度、怪群大小、连接加成、词缀幅度、经验、硫磺百分比、海图不消耗、免费放灯、装备转金币、基础通货转卡组、禁掉装备、怪物至少魔法、附身、众神词缀、荒林鬼灵、怪物分裂、装备破裂、首饰转暗金、噬魂者，都先作为已有目标的注释或提权条件。免费放灯确有操作意义，宜作为区域辅助状态／边缘标记，避免挤占四个“寻找对象”位置。

不能用“杀怪收益提高”凭空增加一个不存在的特殊怪群；但稀有怪／魔法怪数量明确提高时，可以生成对应广义清怪目标。合并后保留所有来源，防止将来自同一奖励链的“海星、稀有怪、神圣石”误算为三个独立要找的对象。

## 不能越过的未确认点

1. **禁装备和暗金策略之间的交互**：datamine 字面禁止怪物掉装备／药剂／酊剂，原作者又将此词缀视为高价值放大器。本次一手资料没有解释内部转化顺序。不能凭直觉写“禁止装备必然禁止所有暗金”，也不能反向编造“装备自动转成暗金／通货”。暂保留为机制待核对注释，不据此删除箱子、Boss、纪念币目标。
2. **实际状态不可知**：静态 layout 不知道灯笼是否已收、箱子是否已洗、赐福是否已拿、精华是否已开。提示用条件式文字，不能自动标记已完成。
3. **目的地机制证据不足**：十二个特殊目的地的精确固定对象和数量没有从此次官方页面全部取得。ref 可用于草案，但发布前应对重点目的地录屏／游戏样本逐条核实。不能宣称已穷尽官方资料。
4. **跨版本与国服同步**：3.29.0b／.1／.2 是国际服补丁来源；国服 S30 当前采用何套规则仍须与客户端比对。配置至少记录游戏版本、来源日期、证据等级和可覆盖权重。
5. **无当前精确利润**：未进行交易行情采集、掉率建模或每小时收益测试。以上权重是“值得占一个跑图提醒位置”的初始判断，供用户调整。
