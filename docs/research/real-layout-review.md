# 真实库存回归子集

`src/logic/__fixtures__/real-inventory-layout.json` 是已获准提交的九张国服海图子集，用于页面几何、区域目标与规划恢复回归。它由航程结束后的剩余库存离线求解得到，不是对已完成游戏航程的原样记录，也不证明七种策略均已实测可执行。

完整私人库存和个人导出文件不进入公开样本。最初分析及其证据边界保存在[固定历史记录](https://github.com/ren2019/allflame-voyage-cn/blob/93d197845d5ca0fe27da54191b877e240b60937b/docs/research/real-layout-review.md)。
