# #14 区域目标实现与验证

规格：GitHub #21；任务：#14。规则版本：`3.29-display-priority-1`。

## 行为

- `src/data/region-targets.json` 是实际加载的版本化展示规则：48目标、七策略覆盖、141词缀、15目的地、区域条件、权重、明确分组与图案来源。维护此配置即可更新固定输出，不把目标判断散到组件分支。
- 中央 overlay 仅推导当前格实际收到的目的地与效果；复用评分的几何范围（物理／连接、自作用、禁用词缀、连接缩放）。没有数值评分的友善水母仍被识别。
- 同一目标重复来源合并取最大展示权重；明确箱子／金币／首领按配置合并。最多四组；超过四组为前三加更多。详情保留组内全部目标、有效权重和全部来源。0权重仅留详情。
- 原有实体信息、分数、库存和求解状态不变。窄屏 overlay 开启时为每格增加只读提示空间，主词缀摘要截短但完整原文仍在既有悬停说明。关闭时回到原布局。
- 高／中／低与明暗主题颜色取自配置；原始游戏图案不染色、不叠字。最终48映射对应39份本地资源，与接受的清单逐字节比对一致；不请求外部CDN。详情保留作者、许可与来源。
- 图标可点击或键盘打开原生 modal；Esc／关闭后焦点返回原图标，不触发海图选择、旋转或交换。

## 真实样例与独立预期

`src/logic/__fixtures__/real-inventory-layout.json` 只保留52张用户真实库存离线重算盘所需的九张海图。它是用户完成航程后导出的库存**重新求解的验证盘**，不是旧航程盘或真实游戏截图。来源见 `docs/research/real-layout-review.md`。

独立预期：中央格5奥术师只供给格2／4／6／8、不供给自身；全航程精华出现于全部九格；左上格出现边界宝藏锚；左上四类目标为锚、普通怪群、魔法怪、精华。共享几何提取前记录的手动 `DEFAULT_WEIGHTS` 基线为78.78（逐格5.67／10.22／6.41／10.72／6.29／10.88／7.10／14.90／6.59）。**实际点金速刷策略权重下的原评分是0**，测试也保持0；78.78不代表页面策略奖励。

额外 JSON 载入样例是明确派生的规则验收模型：多箱／金币／首领合并、重复来源、不连接／自作用／禁用、无数值遭遇、仅神圣边界接收区域提高已有目标、0／1／4／超过4类、同分稳定与1／39／40／69／70／100颜色边界。不得称作新的国服现场证据。
