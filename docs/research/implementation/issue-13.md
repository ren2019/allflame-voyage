# #13 校准模式与库存预留标记

规格：[统一规格 #21](https://github.com/ren2019/allflame-voyage/issues/21)，实施票 [#13](https://github.com/ren2019/allflame-voyage/issues/13)。

- 顶部带可访问名称的铅笔开关控制所有单条校准链接；默认关闭，关闭不渲染、不占位。模式仅保存在 React 会话状态，刷新后关闭，不写入规划备份。
- 链接统一采用紧凑铅笔图标。边界深链接保留记录键和具体槽位，库存和词缀浏览器保留记录键；阻止点击冒泡，不改变选择、边界或停用效果。
- 边界下拉、边界悬停和词缀浏览器只显示词义，维护证据和冲突仍可从校准页查看。未修改导入或功能错误处理。
- 库存格使用独立头尾行容纳形状、实际策略预留、价值、等级、校准和删除。列表头可换行。网格和列表的预留标记可点击／键盘打开所属策略与材料说明；说明明确区分网页预留和游戏内锁定。
- 校准页原有保存、搜索、导入、导出与证据等级行为不变；未修改求解、预留选择、词库或核销逻辑。
