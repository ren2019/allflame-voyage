# #17 当前摆盘的航程历史参考

## 实现边界

当前有效九格摆盘旁显示原评分、同策略同计分口径的最近可比完成次数、运行参考，以及严格低于／等于／高于当前的真实次数与比例。未选策略或当前盘无效时明确说明，样本不足五次不分三档。比较口径默认折叠，可展开阅读；说明个人历史参考不构成攻略门槛或收益保证。

纯只读入口 `compareVoyageHistory(AppState)` 复用 #22 的最终盘有效性、原始评分、实际计分口径和按完成时间排序接口。先过滤同策略与同口径，再取最近三十次。当前盘不会追加到历史，也不删除异口径或旧样本。按未经舍入的分数计算中位秩，严格小于 25%／大于 75% 才进入偏低／较好；边界与当前全部等分归常规。没有更改求解器、评分权重、策略预留、库存核销或历史写入逻辑。
