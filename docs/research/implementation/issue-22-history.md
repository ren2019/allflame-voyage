# #22 完成航程历史

完成核销前读取最终确认的九格、库存实例、连接规则及实时评分设置，保留未经显示舍入的原评分。记录代表网页的“完成航程”事件，不代表游戏出发事件。半盘、重复实例、缺失库存、连接无效或非有限评分不加入历史；既有库存核销仍继续。

每次核销流程生成稳定 completionId；同步提交保护阻止重复最终回调，历史还按身份去重。React 状态更新函数保持纯函数，不在其中触发消息、计时器或生成身份。保留确认可取消，取消不核销、不写历史。求解和候选应用仅改变规划状态。

公共接口在 `src/logic/voyageHistory.ts`：`completedBoardScore` 验证并返回当前完整有效盘原分；`currentScoringContext`、`scoringContextKey` 提供同口径比较键；`createVoyageRecord` 构建完成快照。口径单独携带评分/数据规则版本（评分算法、词缀效果或策略数据语义变化时必须升级），有效权重、策略、邻接、自身生效、禁用词缀及连接模式；不包含库存、边界、存储格式版本或布局软偏好。

历史随本地保存与完整规划 JSON 备份保存；旧文件缺历史正常加载，旧评分版本保留且不改写。恢复逐条验证，损坏历史不导致库存或偏好重置；界面明确提示丢弃损坏历史。存储写入返回成功状态；失败时说明历史未持久化，仍可导出备份，核销结果不回滚、不假报保存成功。

验证：先以浏览器缺少历史入口的失败用例驱动首个完成/刷新/备份闭环，再以损坏备份失败用例驱动恢复处理；独立口径键顺序测试先失败后补齐规范化。相关整页路径覆盖无保留、有保留、取消、半盘、双击、刷新、导入、损坏本地历史、存储写入失败及原有双航程材料保护。规则输入输出测试覆盖原分12.96与显示13.0的区别、软偏好不分桶、旧计分版本及缺库存/重复实例/无效连接。

本票不实现分位建议（#17），不更新现有部署，不宣称 Windows Edge 或游戏现场验证通过。
