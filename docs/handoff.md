# Handoff：航海摆盘工具国服简体版

> 目标：把台服版航海板规划工具改造成**国服（简中）可用**的版本，并部署到 GitHub Pages。
> 背景攻略：[[S30 builds/S30 航海海图攻略.md]]（本文档的对照表即摘自其附录，已核实国服客户端译名）

## 2. 问题定义

工具流程：用户输入 12 条边界词缀 → 游戏内 Ctrl+C 复制海图粘贴进来 → 解析形状/等级/词缀 → 选策略 → 爬山法求解最优 3×3 摆盘。

**国服不可用的根因**：`src/logic/parser.ts` 的正则和 `src/data/mods.ts` 的词缀表都按**台服客户端文本**写的。国服粘贴文本里目的地名、词缀描述、字段标签全是另一套译名（例：台服「奇夏拉安眠地」 vs 国服「琪莎拉安息处」），导致解析失败或错配。形状、物品等级、数量百分比等数字字段与翻译无关，理论上可复用。

## 3. 仓库结构（动手前先读）

```
src/logic/parser.ts      ← 粘贴文本解析器（本次改造核心）
src/logic/solver.ts      ← 求解器（穷举/爬山+多次重启）——不用动
src/logic/scoring.ts     ← 评分逻辑——不用动
src/data/mods.ts         ← 边界词缀 + 海图词缀数据表（要翻译/改名）
src/data/strategies.ts   ← 策略权重定义（文案简中化，权重别动）
.github/workflows/deploy.yml  ← Pages 自动部署，fork 后可直接用
```

## 4. 改造任务清单

### Step 0：采集国服粘贴样本（⚠️ 阻塞项，先于一切）

没有国服 Ctrl+C 原文样本，解析器改不准。需要采集：

- [ ] 普通海图 × 2（不同基底）
- [ ] 金色目的地图 × 2（如锚地、琪莎拉安息处）
- [ ] 已测绘、带「相邻区域…」辐射词缀的图 × 2
- [ ] 带惩罚词缀的图 × 1
- [ ] 边界词缀悬停文本（航程规划板外圈槽位，能 Ctrl+C 就采，不能就截图 OCR）
- [ ] 低级图（<68）× 1（确认等级字段格式）

样本落盘为 `samples/*.txt`，每张图一个文件，作为解析器的 fixture 和回归测试。

### Step 1：改造 parser.ts

- [ ] 对照样本逐字段确认：物品等级行、数量/稀有度行、目的地行、形状行（「海图形状：交叉」）、固定词缀、航行词缀（测绘后揭示）、提示行（「航行词缀将在完成测绘后揭示」）
- [ ] 字段标签正则全部换成国服文案；注意国服标点（全角/半角冒号）可能与台服不同
- [ ] 目的地名匹配表换成国服名（见 §5 对照表）
- [ ] 保留英文兼容（原 parser 已支持中英混贴，英文部分不用动）
- [ ] 每个样本写一个解析单测，断言形状/等级/词缀/目的地全部正确

### Step 2：数据表简中化（mods.ts）

- [ ] 65 条边界词缀池 → 国服文案（权威来源：游戏内航程规划板实际文本；可参考 [[S30 builds/S30 航海海图攻略.md]] 第 1 步盘型表里的国服叫法）
- [ ] 海图航行词缀表 → 国服文案（参考攻略附录 3）
- [ ] 目的地/基底名 → 用 §5 对照表

### Step 3：界面文案简体化

- [ ] 全部 UI 文案繁转简（注意不只是字形转换——「保險箱→保险箱」「詞綴→词缀」「介面→界面」等用词差异）
- [ ] 策略名：速刷保险箱 / 稀有怪传说装 / 魔法怪流 / 稀有怪神圣雨（权重数值不动）

### Step 4：部署

- [ ] Fork 到自己账号 → 确认 Actions 里 deploy.yml 启用 → push main 自动上 Pages
- [ ] 验证 `https://<用户名>.github.io/3.29_Allframe_voyage_planning/`（若仓库改名需同步改 `vite.config` 的 `base`）

### 不做的事

- ❌ **不要搬运 AHK 批量扫仓脚本**——原作者自己标注「疑似踩线」，国服（腾讯）对第三方工具更敏感，直接删掉或 README 明确警告
- ❌ 不改 solver/scoring 算法
- ❌ 不引入后端，保持纯静态

## 6. 验收标准

1. §Step 0 全部样本解析结果与游戏内面板一致（形状/等级/数量/目的地/词缀）
2. 12 条边界词缀可搜索、可选中，文案为简中
3. 贴 9 张图 → 选策略 → 出摆盘方案，结果与台服版同输入（英文模式）一致（算法未动，可作交叉验证）
4. Pages 部署可访问，手机/桌面浏览器均可用

## 7. 风险与备注

- **License 风险**：上游若无 LICENSE，严格说无授权 fork——个人自用+署名一般没问题，公开发布前在原仓库提 issue 问一句
- **译名漂移**：国服新赛季（12 月 7 日后）若机制进核心或改译名，mods 表需跟进
- **交叉验证技巧**：同一份海图数据，英文客户端粘贴喂台服版（其 parser 支持英文），国服粘贴喂本版，两者摆盘结果应一致
