# 游戏词库中文校准

方案 A 已于 2026-10-14 选定，正式页面位于 `?view=calibration`，对应 [#11](https://github.com/ren2019/allflame-voyage/issues/11)。原型与评选记录保存在 `prototype/localization-calibration` 分支（`a2c9b80`）；正式页面仅保留 A。

## 查找和单条编辑

词库覆盖175条：边界、航行、奖励、目的地、海图基底、连接形状和高级复制字段。列表提供位置/用途、英文、当前中文和证据状态，按冲突/缺失、仅来源、已校准排序。

可搜索中文、英文、稳定标识、已保存建议及备注，也可粘贴完整高级复制航行词缀。高级复制中的数值与范围通过已有严格匹配器识别，不猜测其他档位。

主界面顶部“中文校准”打开全表。词缀浏览、已选边界和海图库中的“校准 ↗”在新页打开对应词条；浏览器地址可收藏。右侧修改建议、备注和审阅结果后点击“保存本条”。切换条目保留未保存草稿，刷新或关闭有草稿时会提示；保存后刷新可恢复。

## 保存、导出和备份导入

已保存记录存在当前浏览器、当前网站地址的存储中。不同电脑、浏览器、HTTPS/HTTP地址之间不会自动同步。规划JSON与校准JSON分开。

“导出校准记录”下载已保存记录（不包含未保存草稿），可交给维护者审核后应用到项目。“导入校准记录”合并版本1的备份，保留同条中较新的记录和当前草稿。未知条目、重复标识或损坏字段整份拒绝，已有记录不变。原型“中文化校准-原型建议.json”也可导入；原型没有保存时间，同条已有正式记录时优先保留正式记录。

若本地保存数据无法读取，页面保留原始数据并提供原始备份下载，阻止覆盖。存储空间或访问失败会显示错误，不能把失败视为已保存。

## 证据边界

人工“审阅通过”只改变校准记录，不升级客户端证据。原工具英文、来源英文/中文、候选、作用范围、版本日期和真实高级复制原文分别展示。建议不会直接改变程序译文、解析别名、数值、作用范围、评分、库存或摆盘。

本页首先校准P0游戏词库，界面操作文案等后续优先级尚未进入本表。原有真实游戏搜索、放置及航程现场验收仍见 `docs/acceptance/field-checklist.md`。
