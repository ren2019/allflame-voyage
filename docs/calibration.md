# 中文校准

中文校准用于检查游戏词库，并保存单条译名建议。入口为页头「中文校准」，也可以直接使用站点的 `?view=calibration` 页面。

## 查找与定位

校准表覆盖边界、航行词缀、奖励、目的地、海图基底、连接形状和高级复制字段，提供位置／用途、英文、当前中文及来源证据对照。可搜索中文、英文、内部标识、建议及备注，也可粘贴完整高级复制词缀。

正常规划页默认不铺开维护入口。打开页头铅笔模式后，海图、边界和词缀旁出现紧凑的单条校准链接，直接打开对应记录；关闭铅笔即可恢复正常规划。单条地址可收藏，方便以后回来修改。

## 保存与提交 Issue

修改建议、备注和审阅状态后，点击「保存本条」。已保存记录保留在当前浏览器、当前站点来源；不同电脑或地址之间不会自动同步。

- **提交校准 Issue**：保存后打开预览，默认选择全部有效已保存记录，可取消勾选。搜索、证据筛选和当前查看的单条不会限制提交范围；预览分别显示所选数量与已保存总量。
- 存在未保存草稿时，页面显示草稿数量，可选「保存全部草稿并继续」或「返回编辑」。全部写入成功后，预览才包含最新建议、备注和审阅结果；返回编辑保留当前位置、搜索、筛选及全部草稿。没有已保存记录或未勾选任何记录时不能打开草稿。
- 在预览中核对位置／用途、稳定标识、当前中文、建议、备注、审阅结果及完整 JSON。**校准内容与备注会公开到 GitHub**，请先检查自己填写的内容。
- 完整编码后 URL 不超过 **6,000 字符**时，点击「打开已预填的 GitHub Issue 草稿」，会在 [国服项目 Issues](https://github.com/ren2019/allflame-voyage-cn/issues) 预填标题和包含完整版本 1 JSON 的正文。请在 GitHub 登录、核对并最终发布，无需下载再上传。
- 超过 URL 预算但正文仍在单次预算内时，先点击「复制完整 Issue 内容」，再用「打开 GitHub Issue 草稿」短链接打开仅预填标题的草稿，在 GitHub 正文粘贴后发布。6,000 字符是本站的保守预算，并非 GitHub 官方上限。
- 所有可提交内容都保留复制按钮、可选中的完整正文和仅预填标题的备用链接；它们与预填使用同一份预览快照。剪贴板权限被拒绝或环境不支持时，页面会提示手动复制并选中完整正文。预填草稿被浏览器拦截或网络加载失败时，也可复制正文并用备用链接重试。
- 打开草稿、返回编辑或关闭外站均不表示远端已提交，也不会删除本地记录。维护者仍需核对原文、版本及作用范围。
- 本站以完整正文 **30,000 UTF-8 字节**作为保守单次预算；超出时完整内容保留，但不能继续打开草稿。可减少勾选条目或返回缩短备注后重试。
- **导入校准记录**：合并兼容备份，保留同条较新记录和当前草稿；损坏字段、未知条目或重复标识整份拒绝，原有记录不变。
- 规划完整备份入口保持独立。校准提交只包含所选校准记录，不附带库存、摆盘、航程历史或其他浏览器数据；主动填写的备注会原样公开。

有未保存草稿时，刷新或离开会提示。保存失败会保留已有记录与全部草稿，并停在页面，不继续打开 GitHub；可在编辑框中手动选中并复制建议和备注备份，恢复浏览器存储后再保存。发起提交时会重新检查本地记录；无法读取或损坏的数据会阻止提交和覆盖，并保留可用的原始数据备份入口。原始数据下载仅用于故障恢复，不会混入公开反馈。跨标签页的已保存记录仍会同步，当前标签页的未保存草稿仍保留。

## 来源与生效

客户端原文、网页来源、候选翻译、作用范围和版本分别保留。来源优先核对真实国服高级复制样本，再对照 PoEDB 中英文资料及原版内部定义。

人工「审阅通过」只改变校准记录，不升级客户端证据。保存建议不会直接更改正式译文、解析别名、评分、库存或摆盘；维护者应用配置后才随新版本生效。

普通规划页隐藏来源维护状态；冲突和证据缺口集中在本页查看。需要提供新证据时，附完整原始复制文本和客户端版本，避免只给截断词句。
