## T01：两份真实国服海图导入及失败反馈闭环

### What to build

玩家通过现有导入界面单张或批量录入父规格中的两份真实国服样本，得到正确海图属性；关键航行词缀未知或缺失时使用现有失败反馈。建立最小浏览器自动化入口，使第一项交付本身能演示和验证。

### Acceptance criteria

- [ ] 两份样本分别和合并导入成功，产生正确名称、区域等级83、目的地、形状和两个不同实例。
- [ ] End/Straight连接与110%数量、75%/60%硫磺正确；两个基底效果分别为相邻螃蟹和全航程群规模5%，后者与头部本区域群大小5%分开。
- [ ] 覆盖Windows换行、稀有度标签空格、全角形状冒号、高级roll/range、不可调整后缀及出售提示；正文奖励不重复累加。
- [ ] 派生的未知/缺失/空基底、缺失/未知形状、混合有效/无效输入有明确解析拒绝结果。界面只显示原有数量/类别汇总，无新增待确认UI。
- [ ] 区域等级71、物品等级83、需求等级66的派生输入读取71；英文/韩文原有解析回归通过。
- [ ] 从隔离浏览器通过真实导入控件验证成功与失败，而非只调用解析函数；保留两个样本词缀已有评分参数。

### Blocked by

None，可立即开始；使用父Issue内嵌样本及现有两条映射，不等待全量词库。

## T02：PoEDB国服文本库独立采集、对齐与覆盖审计

### What to build

提供可离线消费且可追溯的国服词缀/文本数据，为后续海图与边界适配提供中文原文和内部ID映射。用户指定PoEDB简中正式站，英文同页和真实客户端样本用于核对。

### Acceptance criteria

- [ ] 采集相关正式中英文页面并保存可重放快照、来源URL/定位、日期、版本或unknown、摘要；避开PTR。
- [ ] 对141个现有词缀ID、15个目的地、5种形状和复制字段逐项登记原文、作用范围、档位/范围、映射依据、真实来源标识及校验状态。
- [ ] 每项检索后标为已校准、仅来源、缺失、未匹配或冲突；缺失项有尝试来源和取得证据的下一步，不以初步pending清单冒充完成采集。
- [ ] 相同metadata或mod/stat ID优先对齐，语义复核如实标记，未知原生ID为空；不按行号合并双语表。
- [ ] 两份真实国服样本及两条词缀与采集库一致；网页模板和客户端roll、后缀、标点差异有显式记录。
- [ ] 当前档位/作用域、硫磺译名和边界空白行等冲突有清单，不改评分或策略参数；原版范围外机制仅记录未匹配。
- [ ] 数据结构、内部ID唯一性、来源存在性、覆盖分母和已核对映射有自动化检查；结果可脱离PoEDB网络消费。
- [ ] 缺少真实形状/边界样本时明确剩余采集请求，不声称全量国服客户端已验证。

### Blocked by

None，可立即开始；独立数据交付，不修改应用UI或求解算法。

## T03：词库驱动的国服库存导入与核心反馈简中化

### What to build

在最小样本闭环上接入已核对的文本库，使支持范围内的国服海图进入原有库存管理，并以简中展示海图、导入和失败反馈；保留原版实例与重复导入行为。

### Acceptance criteria

- [ ] 已核对的中文目的地、形状、奖励和航行词缀映射到已有内部标识；适配五种形状的已取得证据，缺证据项目明确登记而非自行捏造译名。
- [ ] 参数化测试逐条验证可用库中的档位、作用范围及拒绝未知规则，不将缺失/冲突数据静默当成有效映射。
- [ ] 简中库存及导入控件显示正确属性和原有数量/类别反馈，无新增逐物品错误UI。
- [ ] 同批相同实例、整批重扫和没有原版去重字段的行为回归，库存与既有原文保留字段语义一致。
- [ ] 已核对的中英文等价海图在同一摆盘上评分一致，英文/韩文原有测试继续通过。
- [ ] 浏览器验证支持文本的导入、查看库存和重复粘贴闭环，覆盖报告准确列出可支持与尚未核实范围。

### Blocked by

T01、T02。

## T04：国服十二边界词缀选择与效果验证

### What to build

玩家使用已核对的国服名称搜索并填写12个边界位置，界面展示与内部效果正确对应，原版评分行为保持一致。

### Acceptance criteria

- [ ] 原有64个边界ID逐项接入可用简中文案或明确缺口，来源/冲突状态不丢失，不误把PoEDB空白条作为新功能。
- [ ] 浏览器验证简中查找、选择、替换和清空原有边界控件。
- [ ] 原版边界索引0–11直接作用格为0、1、2、2、5、8、6、7、8、0、3、6；逐位置隔离测试以及角落双边界叠加通过，中心没有直接边界效果。
- [ ] 同内部ID的中文选择与原版配置评分一致；直接、每连接、幅度类边界使用原有语义。
- [ ] 固定边界验收数据有离线来源和预期；不能以未采集数据跳过必要验证。

### Blocked by

T02。可使用固定内部海图状态验证边界，不必等待完整国服导入。

## T05：七策略候选摆盘与国服九步定位放置

### What to build

玩家在简中界面沿用七个原有策略及设置求解、选择候选，再按原有九步指南复制国服定位文本。材料不足时可以补充库存重试。

### Acceptance criteria

- [ ] 七策略说明、关键设置和求解反馈简中化，内部策略ID、权重、材料要求、硬约束及软偏好不变。
- [ ] 为七策略分别制作固定可行库存、边界和见证摆盘，记录来源/人工模型性质及保护、中心、布局配置；可行性与实例唯一性先验证。
- [ ] 可执行结果满9格、使用真实不同库存实例、满足连接和原有保护；不可行参考方案不误标可执行。不比较随机求解的唯一排列或固定排名。
- [ ] 点击候选实际载入该方案实例和朝向，后续指南对应选中的盘。
- [ ] 逐次执行9次复制推进，受控剪贴板收到每格对应国服文本，第9次结束；顺序为左下到右上按原有行序，复制不减少库存。
- [ ] 国服定位字段及策略内已有游戏搜索表达式逐一校对，自动化匹配离线样本；真实游戏效果留给现场验证，不以模拟代替。
- [ ] 初始8张不可行库存补入固定第9张后重新求解成功；原有七策略及语言回归通过。

### Blocked by

T03、T04。

## T06：国服规划保存、JSON备份和航程核销循环

### What to build

玩家保留当前国服规划、备份恢复完整状态，并按航程实际消耗/存活更新库存；核销后补库存和更换边界继续下一航程。

### Acceptance criteria

- [ ] 保存、备份和核销的现有控件及反馈简中化，不新增服务器存储、数量交互或同步。
- [ ] 同一浏览器/地址刷新恢复库存、非空摆盘、边界、策略及持久设置。
- [ ] 通过实际导出下载及导入控件验证完整JSON往返；保护、权重、配置、实例与朝向等价，同盘评分一致。
- [ ] 核销移除当前所选摆盘已使用且未存活实例，保留未使用和确认存活实例；九格清空，边界与配置保留。
- [ ] 固定双航程数据验证补库存/更新边界后的第二次规划，不能引用已消耗UID，保留实例按原版规则可再次使用。
- [ ] 每个情形有公开状态/页面结果断言，现有存储、实例和核销行为回归通过。

### Blocked by

T03。可从固定摆盘状态独立验证恢复与核销；不因文案制作顺序增加对T05的技术依赖。最终复制到核销的串联由T08验证。

## T07：Mac Mini手动部署与Windows内网访问

### What to build

在Mac Mini上手动提供当前版本站点，内网Windows能访问并导入已支持的国服样本。确定现有复制在实际访问地址上的可用性并给出启动/停止方式。

### Acceptance criteria

- [ ] 可重复构建并手动启动/停止纯静态站点；约定稳定内网访问方式，不要求开机自启或公网发布。
- [ ] 实际Windows浏览器正常加载资源并导入父规格两份样本；不可访问时定位具体网络/服务条件。
- [ ] 在实际地址检查一键复制的安全上下文与权限；通过部署配置支持原有复制能力，不新增降级UI或全局削弱浏览器保护。
- [ ] 记录启动、访问、停止和验证方式，版本更新可重复执行。
- [ ] 若目标Windows访问或证书配置必须由用户完成，提供具体现场步骤并标示待验，不能将Mac模拟视为Windows验证通过。

### Blocked by

T01。服务可部署最小可用导入版本，后续版本复用同一部署方式。

## T08：完整BDD集成、覆盖核对与国服现场验收

### What to build

将各切片的自动化串成可重复执行的完整用户旅程，给出七类故事与文本库覆盖证据，并验证实际Windows/国服游戏中的定位与放置。

### Acceptance criteria

- [ ] 一个明确的验证入口运行解析/词库、原版回归与本地浏览器BDD；不在线依赖PoEDB或原站。
- [ ] 完整场景串联导入→12边界→策略→求解→选候选→9次复制推进→同盘核销→补库存/更新边界→第二航程；明确失败重试分支。
- [ ] 七类故事/27组场景与实际测试、fixture和执行证据可追溯，缺失必要数据或测试报告未完成，不静默skip。
- [ ] 原版英文/韩文、七策略和评分回归通过；未改变评分算法、权重或原版范围。
- [ ] 对最终版本执行Windows内网访问、复制到真实国服游戏并按指南放置的现场检查，记录结果与剩余资料缺口。
- [ ] 若需要人类提供尚未取得的客户端样本或完成游戏操作，交付明确步骤/样本请求并停在该人类检查点；不得报告现场成功或关闭整体验收直到获得证据。

### Blocked by

T05、T06、T07；T04通过T05间接阻塞，不重复增加直接依赖。
