# 验收数据登记

本文件定义自动化数据集的名称、制作要求与预期，不宣称尚未制作的数据已验证可行。真实样本已存在，其他数据集在测试实现任务中制作并校验后才可标为 ready；不能以跳过测试伪装通过。

## 真实与派生样本

- 已存在：`samples/charted.zh-CN.txt`，两张真实海图；字段 oracle 在 `samples/README.md`。
- 已存在：`src/logic/__fixtures__/charted.en.txt`、`charted.ko.txt` 及其他原有韩文语料，用作兼容回归。
- 派生负例：从国服样本删除基底标记/词缀，清空基底行，替换词缀为明确未知文本，或令区域等级71、物品等级83、需求等级66。派生步骤和原始样本引用必须一同记录。
- 原版完整复制文本与rawText不是同一字段；重复导入测试必须调用真实解析结果，另用人工数据覆盖rawText为空行为。

同一数据集先经连接检查与库存唯一性检查证明其见证可执行，再交给随机求解回归。测试不比较唯一最优排列，不改变算法。用于浏览器国服导入的数据须有对应文本及语言来源；仅用于求解算法的数据可明确标记为人工内部模型，不能假称实测国服原文。

## 十二个边界位置 oracle

九格编号按从上到下、从左到右为0–8，中心4。边界编号按原版 `borderTouches`，不是沿外圈统一顺时针：

| 边界索引 | 位置 | 直接受影响格 |
| --- | --- | --- |
| 0 | 上左 | 0 |
| 1 | 上中 | 1 |
| 2 | 上右 | 2 |
| 3 | 右上 | 2 |
| 4 | 右中 | 5 |
| 5 | 右下 | 8 |
| 6 | 下左 | 6 |
| 7 | 下中 | 7 |
| 8 | 下右 | 8 |
| 9 | 左上 | 0 |
| 10 | 左中 | 3 |
| 11 | 左下 | 6 |

`border-positions` 数据集为每个位置选择一个已核对中文文本的内部边界ID，记录预期直接效果。来源与中文原句来自独立文本库任务，当前尚未齐备。可逐位置单独启用同一个已确认直接效果的边界ID，其他位置为空，以隔离作用区域；四角在两条边界同时启用时各获得两项效果，中心不直接获得任何边界效果。

## 制作完成的门槛

所有表中数据集有实际文件、来源和状态；七策略见证逐个可行；所有引用的内部ID真实存在；派生输入被明确标注；边界中文来源可追溯。完整BDD运行时缺数据应报告未完成，不设为通过。
