# #4 词库驱动的国服库存导入与核心反馈

分支 `implement/issue-4`，从集成提交 `5eb8360` 创建，消费 #3 固定离线证据。应用入口继续为 `parseChartText`、`isChartClipboardText`、`dedupeNewCharts`；评分仍使用原有 `scoreBoard`，没有修改求解/评分或任何 MOD effect。

支持范围：

- 全部 62 个已取得并按语义/档位/作用域复核的航行词缀（43 相邻、19 全航程）映射到原版 ID；两条真实校准、其余为 source-only。逐条参数化检查 CN 模板、原版 ID/scope，并与同 ID 英文等价海图在九个不同实例组成的同位置/朝向摆盘上比较完整评分输出。
- 全部 15 个已取得目的地（两条客户端校准，13 条仅来源）映射到原版区域 ID，不使用网页表格行号。
- 两个已校准形状标签：端点→End、直线→Straight；北/东/南/西连接保持原版定义。Corner、Junction、Crossing 的真实国服标签尚缺，未新增任何猜测的解析别名。旧 EN/KO 库存的这些形状在界面使用“相邻双向连接/三向连接/四向连接”描述拓扑，这些是 UI 文案，不是客户端原文。
- 真实复制已验证数量、亡者硫磺、怪物群大小头部字段；正文奖励不会重复计入，区域等级不使用物品或需求等级代替。冲突奖励模板、网页额外机制不成为关键隐式别名。
- 原始 `implicitText` 保留；`rawText` 仍只按原版过滤保留显式负面属性，用于原版去重。它不是完整复制全文。去重仍只比较保留的 rawText，同批多实例、整批重扫、无 rawText 时全部新增的语义不变。浏览器的派生不同海图同时改变一处真实范围内的显式 roll，避免把同 rawText 的原版重扫误当新实例。

安全拒绝范围：未知或缺失关键航行词缀、未知/缺失形状、未知国服目的地、缺少国服区域等级均整项拒绝，同批有效项继续导入。国服 unknown destination 不会静默存为 undefined，missing 区域等级不会落到80；EN/KO 原有回退和未知隐式保留规则未改变。对有区间的来源模板，仍要求显示区间，普通复制仅给实际 roll 时不猜档位。三种未知形状以及普通/未测绘/低级/真实边界的完整客户端资料请求仍见 #3 覆盖报告。

导入、库存、统计标签、随机示例名称及首次使用说明已简中化，库存以已取得的中文词缀/目的地展示并可中文筛选。原有导入数量、重复数、未测绘类别和无法识别类别仍为汇总，没有新增逐项错误/待确认界面。旧版英文搜索正则和原版英文采集器保留为明确标示的参考，说明与按钮是中文；未做国服采集器或 OCR 改造。

共享展示接口：`src/data/localization.ts` 提供 `voyageModText/voyageModShort/destinationLabel/chartShapeLabel/SCOPE_LABELS`。self 奖励展示只翻译原版 effect 值，不将冲突 PoEDB 文本映射入 parser；STAT 标签/描述翻译只改字符串。
