# 游戏现场核对清单

请在自己认可的候选版本及备份库存下测试，记录实际结果；尚未取得的结果写“未测”或“缺样本”。网页测试及复制成功提示不能替代目标电脑、客户端中的实际结果。

## 记录上下文

记录测试日期、应用提交或版本、浏览器版本、游戏客户端版本，以及当前策略、十二条边界和复现所需海图。附样本前移除无关个人信息；完整私人库存留在自己设备。

## 导入与搜索

1. 从实际国服客户端高级复制海图，核对名称、区域等级、目的地、形状及关键词缀。完整原文和预期一起保存。
2. 从实际 Windows Edge 复制完整定位串，手动粘贴到游戏搜索栏，确认正确海图命中、易混淆海图不命中，记录具体表达式和样本。
3. 对使用到的每种留图策略分别核对完整长串、正负样本及游戏容量；截断、超限或不兼容按实际失败记录，不用短串替代后声称原串通过。

## 摆放与跑图

1. 确认候选使用持有的九张实例，逐格核对朝向、连接和已锁定位置；需要保护的实物海图由玩家在游戏中手动管理。
2. 对照区域目标详情核对目的地固有目标、本区域、相邻及全航程效果。图案是显示符号，不足以单独证明机制或固定数量。
3. 按当前策略检查边界价值和分析理由；边界权重与摆盘分数分别理解，不把分档当作收益承诺。

## 核销与恢复

1. 实际完成有效航程后，回到工具确认存活海图和消耗；确认库存只扣除实际消耗项。
2. 核对只新增一条航程历史，刷新后仍在；个人历史样本不足时显示不足，不伪造多次真实航程。
3. 导出完整规划备份，在受控条件下恢复，核对库存、摆盘、边界、策略、预留、配置与历史。准备继续跑图前确认恢复的是所需状态。

反馈时区分“通过”“失败”“未测／缺样本”，附最小复现、完整搜索表达式及实际观察。与现有议题相关时直接补充证据，避免把旧构建的结果归到新版本。
